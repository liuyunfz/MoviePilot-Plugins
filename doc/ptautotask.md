# PT 自动任务

按 MoviePilot 中已有站点配置执行签到、喊话、领取任务及站点福利，任务按站点动态显示。插件 ID 为 `PTAutoTask`，当前版本 `1.2.0`。

## 配置

1. 在 MoviePilot 站点管理中配置站点地址及有效 Cookie。
2. 安装插件，在配置页选择需要执行的站点任务。
3. 设置周期、失败重试和通知选项，保存并启用；首次使用可先运行一次。
4. 在详情查看按运行批次保存的历史，通知按站点汇总。

已实现的站点模块包括 Car、青蛙、青虫、柠檬、LGS、维可萌和织梦。具体任务以当前配置页为准；仓库中的 `.bak` 文件不会作为站点模块加载。

## 1.2.0 变更

- 新增 `TaskResult` 统一结果类型，支持成功、失败、数据和说明。
- 保留包装器对应的任务类，执行时使用 MoviePilot 当前站点的 Cookie，避免误用扫描阶段创建的空会话。
- Car 任务领取达到人数上限时明确标记失败，历史和通知不会显示内部对象。
- 重试次数达到上限后停止继续安排重试。

开发站点任务可参照 [开发说明](develop_ptautotask.md)，显式使用 `self.ok(message="完成")` 或 `self.fail("失败原因")` 返回结果。详情与通知只展示摘要，不应把 Cookie、Token 或整个响应对象用作摘要。

验证覆盖结果归一化、Cookie 传递、失败通知和重试上限；未使用真实站点账号执行任务。
